{# The arkhe mark: the alpha of ἀρχή. It is the first letter of the word for a beginning or a first principle: the point where a reference starts. A drawn symbol was avoided, because it would be read as a generic icon for sharing or branching and say nothing about what it marks. A letter reads as itself. It is drawn as a path rather than set in a font, so its shape does not change from one environment to another. #}
